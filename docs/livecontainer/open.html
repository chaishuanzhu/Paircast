经 LiveContainer 打开邀请

系统无法直接把 paircast:// 交给容器内 App。把链接 Base64 后走 livecontainer://open-url 即可中转。

快捷指令（推荐）

在 iPhone 上下载并添加后：复制邀请链接 → 运行快捷指令；也可从分享菜单选用。

下载快捷指令 软件源说明

添加失败时：打开「快捷指令」App → 文件 App 里点该文件 → 「添加快捷指令」。首次运行需允许打开 LiveContainer。

网页中转

把邀请链接贴到下面，点打开（需已安装 LiveContainer，且已装 Paircast）。

  1. 快捷指令逻辑：输入 URL → Base64（无换行）→ 打开 livecontainer://open-url?url=…
  2. LiveContainer 收到后会把原始 paircast:// 交给已安装的 Paircast
  3. 若弹出「运行 App」，选允许即可
