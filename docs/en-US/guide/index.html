Paircast User Guide

Paircast is an invite-only private cloud sync player. Videos come from the media library that the admin of your self-hosted GO-IM server connects to your own storage. Accounts are created by the admin of your self-hosted GO-IM server — there is no in-app sign-up. Available on iOS and Android; both can join the same room.

Fast path: get a paircast://config?… link from your admin → Login → Service Configuration → Paste to Import → sign in with your assigned account and password.

1. Typical flow

  1. Finish Service Configuration (import a link or enter the IM server address).
  2. Sign in with the account and password your admin gave you. If the admin requires it, you must set a new password on first sign-in.
  3. Browse mp4 / m4v / mkv files from the server media library on the Library screen.
  4. Open a title to create/join a room for synced playback and chat.
  5. Share an invite link so friends can join the same room.

2. Where each configuration value comes from

Open Service Configuration from the login screen or Me.

Since version 2.1 the app only needs the IM server address. Shared config links contain nothing else, and friends still sign in with their own account. After a successful import, sign in again.

2.1 IM server (required)

Field in AppWhere to get itNotes
IM Server address The admin who runs your GO-IM server e.g. im.example.com; HTTPS is assumed unless you type http:// (LAN only)
Login account / password Created by the admin (GO-IM /admin/users/create) Account is your UID or email. Change your password any time in Me → Change Password

The server must run a GO-IM build that supports transient group signals (used for playback sync).

2.2 Media library (configured on the server)

Videos, sidecar subtitles, posters, online subtitle search, and stickers are provided by the GO-IM server. You do not enter storage keys or API tokens in the app. Your admin sets them up once on the server:

  • Video sources: S3-compatible storage (Qiniu, Alibaba Cloud OSS, Tencent Cloud COS, MinIO, …) under gateway.media.sources. Keys are injected through the environment variables GOIM_MEDIA_<ID>_ACCESS_KEY / _SECRET_KEY. Read-only access is enough: the server issues short-lived playback links and the video stream does not pass through it.
  • Posters and overviews: a {name}.nfo / {name}-poster.jpg next to the video is used first. Otherwise the server queries TMDB when GOIM_TMDB_ACCESS_TOKEN is set.
  • Online subtitles: enabled when GOIM_OPENSUBTITLES_API_KEY is set on the server.
  • Stickers: set stickers_source / stickers_prefix (default stickers/) and put catalog.json and {pack_id}/pack.json there. python3 Scripts/build-stickers.py --src /path/to/Stickers --out ./stickers-dist builds this layout from a local sticker dump.

See the “媒体库（Paircast）” section of the GO-IM deploy README for the full setup. The old _paircast/ folder in the bucket is no longer used: rooms are stored in the server's MySQL and shared subtitles in its file storage.

If the server lists more than one source, the Library screen shows a source picker.

3. Import / share configuration

  1. Import: Service Configuration → Paste to Import or Scan QR Code → confirm overwrite → sign in again.
  2. Or open a paircast://config?args=… deep link.
  3. Links from older versions still import, but their storage keys and API tokens are ignored, because the library is now configured on the server. Links without an IM server address ask you to enter it.
  4. Share: Share Configuration creates an encrypted link and QR code containing the IM server address.

4. Login and library

  • Enter the assigned account and password.
  • If config is incomplete, enter the IM server address first.
  • “The server has no media library configured”: ask the admin to add a video source on GO-IM. Empty library: ask the admin to check that the source (and prefix) contains .mp4 / .m4v / .mkv files.

5. Watch together and invites

  1. Tap a title → room (host can drive sync).
  2. Invite: system share or copy the invite link (https://paircast.chaisz.com/invite/?roomId=…); it opens Paircast on iOS or Android.
  3. Friends need an account on the same GO-IM server (same IM server address) before opening the invite.
  4. Long-press a chat message to Block (local) or Report.

6. Me

  • Avatar, nickname, change password, theme, language
  • Service Configuration, Acknowledgements, privacy/support links
  • Sign out keeps local cloud config
  • Delete Account clears your avatar and on-device config/session; the GO-IM account itself must be disabled by an admin

7. Troubleshooting

  • Invalid config link: copy the full URL; failed imports do not overwrite existing config.
  • Import looks OK but nothing changed: sign in again.
  • Videos do not play: playback links expire after a few hours; go back to the library and open the title again. Admins: the S3 endpoint must be the regional API host, not a CDN domain.
  • Login fails: check the IM server address and that the account exists on that server; “Cannot reach the IM server” means the address or network is wrong.
