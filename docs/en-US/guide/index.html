Paircast User Guide

Paircast is an invite-only private cloud sync player. Videos come from your own object storage. Accounts are provisioned in Tencent Cloud IM by an admin — there is no in-app sign-up.

Fast path: get a paircast://config?… link from your admin → Login → Service Configuration → Paste to Import → sign in with your assigned User ID.

1. Typical flow

  1. Finish Service Configuration (import a link or fill fields manually).
  2. Sign in with an admin-assigned User ID (no password; UserSig is generated on-device from the IM SecretKey).
  3. Browse mp4 / m4v / mkv files in your bucket on the Library screen.
  4. Open a title to create/join a room for synced playback and chat.
  5. Share an invite link so friends can join the same room.

2. Where each configuration value comes from

Open Service Configuration from the login screen or Me.

Shared config links contain IM and object-storage secrets. Share only with trusted friends. After a successful import, sign in again.

2.1 Tencent Cloud IM (required)

Field in AppWhere to get itNotes
SDKAppID Tencent Cloud IM console → your app Numeric application ID
SecretKey Same app → key management (UserSig signing key) Stored in Keychain; UserSig is generated locally — users never paste a UserSig
Login User ID IM console → account management (or your import tooling) Must be created by an admin first

Docs: Tencent Cloud IM.

2.2 Object storage (required)

Providers: Qiniu (S3), Alibaba Cloud OSS, Tencent Cloud COS, MinIO. Required: AccessKey, SecretKey, Bucket, Endpoint.

FieldWhere to get itNotes
Provider Match your cloud Controls Endpoint validation
AccessKey / SecretKey Cloud IAM / key console Prefer least-privilege keys
Bucket Bucket / space name Videos live here (optional Prefix)
Endpoint Regional API host (no https://, no path) Do not put a CDN / custom download domain here
Region (optional) Region id from the console Often blank — inferred from Endpoint
Custom domain (optional) HTTPS domain bound to the bucket Mostly for avatar downloads; enable HTTPS cert in the cloud console
Prefix (optional) e.g. movies/ Limits library listing
HTTPS / Path-Style URL — Public clouds: HTTPS on; MinIO often HTTPS off + Path-Style on

2.2.1 Chat stickers (optional)

In-room sticker packs are loaded from the same object storage:

  • {Prefix?}stickers/catalog.json — pack index
  • {Prefix?}stickers/{pack_id}/pack.json — pack manifest
  • {Prefix?}stickers/{pack_id}/… — sticker images (png / gif, etc.)

After an admin uploads packs under stickers/, members can open the emoji panel in chat. Unicode emoji are rendered with Twemoji.

Use the repo script to convert a local sticker dump into this layout, then upload:

python3 Scripts/build-stickers.py --src /path/to/Stickers --out ./stickers-dist
# Upload stickers-dist/ contents to your bucket under stickers/

3. Import / share configuration

  1. Import: Service Configuration → Paste to Import → confirm overwrite → sign in again.
  2. Or open a paircast://config?args=… deep link.
  3. Share: Share Configuration creates an encrypted link (contains secrets).

4. Login and library

  • Enter only the assigned User ID.
  • If config is incomplete, finish IM + storage first.
  • Empty library: confirm the bucket (and prefix) has .mp4 / .m4v / .mkv and the key can list/get objects.

5. Watch together and invites

  1. Tap a title → room (host can drive sync).
  2. Invite: system share or copy
    paircast://watch?roomId=…&movieId=…&hostUserId=…
  3. Friends need the same cloud config and a valid User ID before opening the invite.
  4. Long-press a chat message to Block (local) or Report.

6. Me

  • Avatar, nickname, theme, language
  • Service Configuration, Acknowledgements, privacy/support links
  • Sign out keeps local cloud config
  • Delete Account clears on-device config/session/avatar; console IM users must be disabled by an admin

7. Troubleshooting

  • Invalid config link: copy the full URL; failed imports do not overwrite existing Keychain config.
  • Import looks OK but nothing changed: sign in again; do not Save empty SecureFields right after import.
  • Endpoint errors: use the API regional host (table above), not a CDN domain.
  • Login fails: User ID must exist in the same IM app as SDKAppID/SecretKey.
