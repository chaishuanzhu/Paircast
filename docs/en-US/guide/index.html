Paircast User Guide

Paircast is an invite-only private cloud sync player that works with a self-hosted server. The server handles accounts, chat, playback sync and the media library (videos stay in your own storage). You can sign up with your email in the app (registration is open by default; the admin can close it), or the server admin can create an account for you. Available on iOS and Android; both can join the same room.

Fast path: ask the server admin for the server address → on the login screen open Service Configuration, enter the server address and save → tap Create Account to sign up with your email (or sign in with an account the admin gave you).
No server yet? Follow the Server Deployment Guide; with Docker it takes about ten minutes.

1. Typical flow

  1. Enter the server address in Service Configuration and save.
  2. Create an account with your email, or sign in with the account and password your admin gave you. If the admin requires it, you must set a new password on first sign-in.
  3. Browse mp4 / m4v / mkv files from the server media library on the Library screen.
  4. Open a title to create/join a room for synced playback and chat.
  5. Share an invite link so friends can join the same room.

2. Service Configuration

Open it from the top right of the login screen, or from Me → Service Configuration after signing in. There is a single field:

Field in AppWhere to get itNotes
Server address Whoever deployed the server (you or a friend) e.g. im.example.com; HTTPS is assumed. Only on a LAN, type something like http://192.168.1.10:8080
Login account / password Sign up in the app with your email, or get one from the server admin Account is your UID or email. Change your password any time in Me → Change Password
Changing the server address while signed in signs you out. Sign in again with an account on the new server.

The media library is configured on the server

Videos, sidecar subtitles, posters, online subtitle search, and stickers all come from the server; you never enter storage keys or API tokens in the app. See Server Deployment Guide · Media library for video sources, TMDB, OpenSubtitles and stickers. If the server lists more than one source, the Library screen shows a source picker.

3. Sign-up, login and library

  • Sign up: on the login screen tap Create Account → enter your email and tap Send Code → type the 6-digit code from the email (valid for 10 minutes), choose a password (at least 6 characters), nickname optional → you land in the library.
  • No Create Account button: the admin has closed registration or the server has no email (SMTP) set up yet. Ask the admin for an account.
  • No code arriving: check your spam folder. One code per email every 60 seconds, at most 10 per day.
  • Existing account: enter your account (UID or email) and password.
  • If config is incomplete, enter the server address first.
  • “The server has no media library configured”: ask the admin to add a video source. Empty library: ask the admin to check that the source (and prefix) contains .mp4 / .m4v / .mkv files.

4. Watch together and invites

  1. Tap a title → room (host can drive sync).
  2. Invite: system share or copy the invite link (https://paircast.chaisz.com/invite/?roomId=…); it opens Paircast on iOS or Android.
  3. Friends need an account on the same server, with the same server address in Service Configuration, before opening the invite.
  4. Long-press a chat message to Block (local) or Report.

5. Me

  • Avatar, nickname, change password, theme, language
  • Service Configuration, Acknowledgements, privacy/support links
  • Sign out keeps the local service configuration
  • Delete Account asks for your current password, permanently deletes the account from the server, and clears on-device config, session and caches. The email can be used to sign up again. Admin accounts can't be deleted in the app

6. Troubleshooting

  • Cannot reach the server: check the spelling of the address, whether it needs http:// (LAN only), and your network. Admins can run curl https://your-domain/health to confirm the server is up.
  • Wrong account or password / account not found: make sure the account was created on the server you entered.
  • Videos do not play: playback links expire after a few hours; go back to the library and open the title again. Admins: the S3 endpoint must be the regional API host, not a CDN domain.
  • Playback is out of sync: make sure both of you are on the same server and have a working connection.
