Paircast Support

Paircast only plays files from your own cloud storage. Rooms are invite-only.

  • Bugs and usage issues: open a GitHub Issue.
  • Chat reports: include that the room is invite-only, your user ID, the other user’s ID, and an approximate time.
  • Account deletion: App → Me → Delete Account.
  • Privacy policy: Paircast Privacy Policy
