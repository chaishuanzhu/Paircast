Paircast Support

Paircast (iOS and Android) only plays files from your own cloud storage. Rooms are invite-only. Accounts are created by the admin of your server; there is no sign-up in the app.

  • User guide (where to get the server address, how to use the app): Paircast User Guide
  • Run your own server: Server Deployment Guide
  • Bugs and usage issues: open a GitHub Issue.
  • Chat reports: long-press the message in the app and choose Report so the server’s admins can act on it. If you contact us instead, include that the room is invite-only, your account, the other user’s account, and an approximate time.
  • Getting an account: ask your server admin, who can add you in the app under Me → Admin Console → User Management → Add User (top right) with your email. For a forgotten password, contact the admin as well.
  • Account deletion: App → Me → Delete Account, then enter your password. The account is permanently deleted from the server.
  • Terms of Service: Paircast Terms of Service
  • Privacy policy: Paircast Privacy Policy
