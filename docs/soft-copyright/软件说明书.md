## 1. 概述

### 1.1 软件用途

Paircast 面向需要「异地一起看同一部私人影片」的用户。影片存放在用户自己的对象存储中，账号由即时通讯（IM）服务预置，应用内不提供公开注册与公共片库。

### 1.2 主要功能列表

1. 服务配置：填写或导入对象存储与 IM 等凭证，保存在本机钥匙串。  
2. 登录：使用管理员分配的 User ID 登录（无传统密码字段）。  
3. 片库：列出云端音视频对象，展示标题、海报等元数据（可选第三方元数据服务）。  
4. 观影房间：创建或加入邀请制房间，同步播放控制。  
5. 邀请：生成邀请链接，好友打开后进入同一房间。  
6. 房内聊天：文字、表情、贴纸；支持屏蔽与举报。  
7. 字幕：内嵌轨、外挂文件、可选在线检索；支持时间轴延迟校准。  
8. 个人中心：昵称头像、主题与语言、隐私与支持入口、删除账号。  

### 1.3 不适用场景

- 不提供商业影视点播目录。  
- 不向未受邀用户分发影片文件。  
- 不替代对象存储或 IM 服务商的合规义务。

## 3. 安装与启动

1. 从 App Store 安装「Paircast Play」。  
2. 首次启动进入登录界面。  
3. 若尚未配置云服务，先打开「服务配置」完成导入或手动填写。  
4. 输入 User ID 登录后进入片库。  

---

## 4. 服务配置

### 4.1 入口

登录页或「我的」→ 服务配置。

### 4.2 必填项（概要）

- 腾讯云 IM：SDKAppID、SecretKey（用于本机签发 UserSig）。  
- 对象存储：AccessKey、SecretKey、Bucket、Endpoint、路径风格与 SSL 等。  

### 4.3 可选项

- OpenSubtitles API Key：在线字幕检索。  
- TMDB API Read Access Token：影片标题、简介、海报等。  

### 4.4 配置分享

可将配置封装为加密深链 `paircast://config?args=…` 分享给可信同伴。链接含敏感凭证，禁止公开发布。导入成功后需重新登录。

（鉴别材料中请勿粘贴真实 `args` 载荷。）

## 5. 登录与账号

1. 使用管理员分配的 User ID 登录。  
2. 登录成败以 IM 登录结果为准。  
3. 可在「我的」编辑昵称与头像（头像上传至用户自有存储）。  
4. 「删除账号」清除本机配置、会话与相关缓存对象并退出登录；控制台侧预置账号由管理员另行处理。  

---

## 6. 片库

1. 登录后展示 Bucket 中符合扩展名规则的影片对象（如 mp4、m4v、mkv）。  
2. 可按前缀/目录浏览。  
3. 若配置了元数据服务或同目录 NFO/海报，界面可显示更友好的标题与封面。  
4. 点选影片可创建或进入观影房间。  

---

## 7. 观影房间与邀请

1. 从片库打开影片后进入播放房间。  
2. 房主可控制播放、暂停、跳转；成员跟随同步。  
3. 可通过邀请链接邀请好友；链接携带房间与影片等必要参数。  
4. 房主离开超时后，按加入顺序自动转让房主；最后一人离开则结束房间。  
5. 房主可切换当前影片，全员跟随。  

---

## 8. 同步播放说明

1. 播控通过 IM 自定义信令传递（play / pause / seek / heartbeat / movie_change 等）。  
2. 仅当前房主发出的播控对全员生效。  
3. 心跳用于校正进度偏差，避免频繁无效 Seek。  
4. 本地播放器基于 VLCKit，以适配常见容器与编码。  

---

## 9. 房内聊天

1. 仅房间成员可见。  
2. 支持文字、系统表情（Twemoji）及自定义贴纸包（来自用户对象存储目录）。  
3. 长按消息可屏蔽发送者或跳转举报流程。  

---

## 10. 字幕

1. **内嵌字幕**：从影片流中选择音轨/字幕轨。  
2. **外挂字幕**：读取与影片同目录的字幕文件。  
3. **在线字幕**：在配置 OpenSubtitles 后搜索并下载。  
4. 房主可将选定外挂/在线字幕上传为共享文件并通知成员加载；时间轴偏移一般为各端本机设置。  

---

## 11. 「我的」与其它设置

1. 主题：浅色 / 深色 / 跟随系统。  
2. 语言：跟随应用语言设置（支持中英文界面）。  
3. 隐私政策与支持页：打开公开网页（如 https://paircast.chaisz.com/ ）。

## 13. 数据处理与安全要点

1. 云凭证保存在系统 Keychain。  
2. 聊天与信令经用户配置的 IM 服务投递。  
3. 影片数据存储于用户自有 Bucket，经预签名 URL 播放。  
4. 可选第三方仅在用户主动填写密钥/令牌后调用。  
5. 详细隐私说明见公开发布的隐私政策页面。

## 15. 技术架构摘要（说明书附录）

本软件采用分层结构：

- **Domain**：配置模型、校验规则、房间用例等与平台无关的业务逻辑。  
- **Data**：Keychain、S3 兼容存储、IM 网关、字幕与元数据网关。  
- **Presentation**：SwiftUI 界面与播放器封装。  
- **App**：应用入口与依赖组装。  

第三方 SDK 包括但不限于：腾讯云 IM SDK、VLCKit 等，按其许可证使用，不改变本软件著作权归属声明范围（以登记申请表为准）。
