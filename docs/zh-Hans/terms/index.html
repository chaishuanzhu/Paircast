Paircast 用户协议

生效日期：2026-11-02。注册或登录 Paircast 前，请仔细阅读本协议与《隐私政策》。勾选同意并继续注册或登录，即表示你已阅读、理解并接受这两份文件。不同意的，请不要注册或登录。

1. 服务是什么

Paircast 是邀请制的私人云同步播放客户端（iOS / Android），让受邀好友在同一房间同步播放、边看边聊。Paircast 本身不提供、不托管、不分发任何影视内容。账号、聊天、播放同步与片库都运行在你所连接的自托管 GO-IM 服务器上，该服务器由其运营方（通常是邀请你的人）部署和管理，不由 Paircast 开发者运营。

2. 账号

  • 你可以用邮箱在服务器上注册（服务器开放注册时），或使用服务器运营方为你创建的账号。注册时请填写你本人能接收邮件的真实邮箱。
  • 请妥善保管密码，不要与他人共用账号。账号下的操作视为你本人所为。
  • 服务器运营方可以关闭注册、停用或删除账号。你可以随时在 App「我的 → 删除账号」注销自己的账号。

3. 你的内容与使用规范

  • 片库中的影片、字幕、海报等由服务器运营方接入其自有存储。只能播放你们合法拥有或已获授权的内容，不得用 Paircast 传播盗版或侵犯他人知识产权的内容。
  • 你在房间内发送的文字、表情等内容由你负责。不得发布违法、色情、暴力、骚扰、歧视、诈骗或侵犯他人隐私的内容。
  • 不得干扰或破坏服务器与其他用户的正常使用，不得尝试未经授权访问他人账号或数据，不得对 App 进行反向工程用于违法目的。
  • 遇到不当内容或用户，可长按消息屏蔽或举报；举报会提交给服务器管理员审核，违规账号可能被封禁。

4. 服务器运营方的责任

自托管服务器的运营方负责其服务器上的账号管理、片源合法性、聊天记录保管与用户投诉处理，并应遵守所在地法律。Paircast 开发者无法访问或控制第三方运营的服务器及其中的数据。

5. 第三方服务

服务器运营方可能接入兼容 S3 的对象存储、OpenSubtitles、TMDB 等第三方服务，这些服务受其各自条款约束。本产品使用 TMDB API，但未经 TMDB 认可或认证。App 使用的开源组件见 App 内「我的 → 致谢」。

6. 免责声明

Paircast 按“现状”提供。由于服务器由第三方自行部署，我们不保证服务不中断、无错误，也不对服务器上的内容、数据丢失或第三方行为承担责任。在法律允许的范围内，Paircast 开发者不对因使用或无法使用本 App 造成的间接损失负责。

7. 终止

你可以随时停止使用并注销账号。若你违反本协议，服务器运营方可以停用你的账号；我们也可以在 App 更新中停止支持违规用途。

8. 协议变更

我们可能更新本协议，并在本页更新生效日期。重大变更会在 App 更新说明中提示；变更后继续使用即视为接受新版本。

9. 联系

问题与举报：支持页 或 GitHub Issues。
