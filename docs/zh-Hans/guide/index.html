Paircast 使用说明

Paircast 是邀请制私人云同步播放工具：影片来自自托管 GO-IM 服务器管理员接入的片库（你们自己的存储），账号由自托管 GO-IM 服务器的管理员创建，应用内不提供注册。支持 iOS 与 Android，两端可以同房观影。

最快上手：让管理员发给你一条 paircast://config?… 配置链接 → 在登录页打开「服务配置」粘贴导入 → 用分配的账号和密码登录。

1. 整体使用流程

  1. 完成服务配置（导入链接或填写 IM 服务器地址）。
  2. 使用管理员分配的账号和密码登录；若管理员要求，首次登录需先设置新密码。
  3. 在片库浏览服务端片库中的 mp4 / m4v / mkv。
  4. 点开影片创建/加入房间，同步播放，并可边看边聊。
  5. 通过邀请链接把好友拉进同一房间。

2. 服务配置从哪里填、值从哪里拿

入口：登录页右上角 / 「我的」→ 服务配置。

2.1 版起 App 只需要 IM 服务器地址，「分享配置」生成的链接也只包含它，好友仍需用自己的账号登录。导入成功后请重新登录。

2.1 IM 服务器（必填）

App 字段从哪里获取说明
IM 服务器地址 运营 GO-IM 服务器的管理员 如 im.example.com；默认 HTTPS，仅局域网可写 http://
登录账号 / 密码 由管理员创建（GO-IM /admin/users/create） 账号为 UID 或邮箱；可在「我的 → 修改密码」随时改密

服务器需运行支持瞬时群信令的 GO-IM 版本（用于播放同步）。

2.2 片库（在服务端配置）

视频、外挂字幕、海报、在线字幕搜索和表情包都由 GO-IM 服务器提供，App 里不再填写存储密钥或第三方令牌。管理员在服务端一次性配置：

  • 片源：在 gateway.media.sources 添加 S3 兼容存储（七牛、阿里云 OSS、腾讯云 COS、MinIO 等），密钥通过环境变量 GOIM_MEDIA_<ID>_ACCESS_KEY / _SECRET_KEY 注入。只需只读权限：服务端签发短时效播放直链，视频流不经过网关。
  • 海报与简介：优先读取视频同目录的 {主名}.nfo / {主名}-poster.jpg；否则在配置了 GOIM_TMDB_ACCESS_TOKEN 时由服务端查询 TMDB。
  • 在线字幕：服务端配置 GOIM_OPENSUBTITLES_API_KEY 后开启。
  • 表情包：设置 stickers_source / stickers_prefix（默认 stickers/），目录下放 catalog.json 与 {pack_id}/pack.json。可用 python3 Scripts/build-stickers.py --src /path/to/Stickers --out ./stickers-dist 把本地表情包整理成该结构。

完整步骤见 GO-IM 部署说明的「媒体库（Paircast）」一节。存储桶里旧的 _paircast/ 目录不再使用：房间存在服务端 MySQL，共享字幕存在服务端文件存储。

服务端配置了多个片源时，片库页会出现片源切换。

3. 导入 / 分享配置

  1. 导入：服务配置 → 粘贴导入或扫描二维码 → 确认覆盖 → 按提示重新登录。
  2. 也可直接打开管理员发来的 paircast://config?args=… 深链。
  3. 旧版本生成的链接仍可导入，但其中的存储密钥和第三方令牌会被忽略（片库已改由服务端配置）；不含 IM 服务器地址的链接需要补填。
  4. 分享：点「分享配置」，生成只含 IM 服务器地址的加密链接与二维码。

4. 登录与片库

  • 输入管理员分配的账号和密码，点登录。
  • 若提示未完成配置，先回服务配置填写 IM 服务器地址。
  • 提示「服务器尚未配置片库」：请管理员在 GO-IM 添加片源。片库为空：请管理员确认片源（及 prefix）下确有 .mp4 / .m4v / .mkv。

5. 同步观看与邀请

  1. 在片库点选影片 → 进入房间（房主可控制播放同步）。
  2. 邀请好友：房间内用系统分享或复制邀请链接（https://paircast.chaisz.com/invite/?roomId=…），iOS / Android 均可打开。
  3. 好友需在同一 GO-IM 服务器（同一 IM 服务器地址）上有账号，再打开邀请链接。
  4. 房间内可文字聊天；长按消息可屏蔽（本机）或举报。

6. 「我的」常用功能

  • 头像 / 昵称、修改密码、主题、语言
  • 服务配置、致谢与隐私/支持链接
  • 退出登录：保留本机云配置
  • 删除账号：清除头像与本机配置、会话；GO-IM 账号本身需管理员另行停用

7. 常见问题

  • 配置链接无效：确认完整复制；导入失败不会覆盖已有配置。
  • 导入后仍像旧配置：按提示重新登录。
  • 视频播不了：播放直链几小时后过期，回到片库重新打开即可。管理员：S3 Endpoint 必须是 API 地域域名，不要填 CDN 域名。
  • 无法登录：检查 IM 服务器地址，以及账号是否已在该服务器创建；提示「无法连接 IM 服务器」说明地址或网络有误。
