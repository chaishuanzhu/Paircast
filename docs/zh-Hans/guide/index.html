Paircast 使用说明

Paircast 是邀请制私人云同步播放工具，需要搭配一台自托管服务器使用：服务器负责账号、聊天、播放同步和片库（影片放在你们自己的存储里）。账号由服务器管理员创建，App 内不提供注册。支持 iOS 与 Android，两端可以同房观影。

最快上手：向服务器管理员要服务器地址 → 登录页打开「服务配置」，填写服务器地址并保存 → 用管理员给的账号密码登录。
还没有服务器？看 服务端部署指南，用 Docker 十分钟左右即可搭好。

1. 整体使用流程

  1. 在服务配置填写服务器地址并保存。
  2. 使用管理员分配的账号和密码登录；首次登录需先设置新密码。
  3. 在片库浏览服务器片库中的 mp4 / m4v / mkv。
  4. 点开影片创建/加入房间，同步播放，并可边看边聊。
  5. 通过邀请链接把好友拉进同一房间。

2. 服务配置

入口：登录页右上角，或登录后「我的」→ 服务配置。App 里只需要填一项：

App 字段从哪里获取说明
服务器地址 部署服务器的人（你自己或好友） 如 im.example.com；默认 HTTPS，仅局域网可写 http://192.168.1.10:8080 这类地址
登录账号 / 密码 服务器管理员创建：初始密码会发到你的邮箱，或由管理员直接告诉你 账号为 UID 或邮箱；可在「我的 → 修改密码」随时改密
登录后更换服务器地址会退出当前账号，需要用新服务器上的账号重新登录。

片库在服务器上配置

视频、外挂字幕、海报、在线字幕搜索和表情包都由服务器提供，App 里不填写任何存储密钥或第三方令牌。片源、TMDB、OpenSubtitles、表情包的配置方法见 服务端部署指南 · 片库。服务器配置了多个片源时，片库页会出现片源切换。

3. 账号、登录与片库

  • 获取账号：App 不提供注册，请找服务器管理员添加。管理员在「我的 → 后台管理 → 添加用户」填你的邮箱即可；初始密码发到你的邮箱（收不到请查看垃圾邮件），或由管理员直接转交。
  • 登录：输入账号（邮箱或 UID）和密码，首次登录按提示设置新密码。
  • 管理员添加用户：「我的 → 后台管理 → 添加用户」→ 填邮箱（昵称可不填）→ 添加。服务器配了邮件时初始密码自动发给对方；没配时页面显示初始密码，点「复制」后自行发给对方（离开页面后不再显示）。
  • 若提示未完成配置，先回服务配置填写服务器地址。
  • 提示「服务器尚未配置片库」：请管理员添加片源。片库为空：请管理员确认片源（及 prefix）下确有 .mp4 / .m4v / .mkv。

4. 同步观看与邀请

  1. 在片库点选影片 → 进入房间（房主可控制播放同步）。
  2. 邀请好友：房间内用系统分享或复制邀请链接（https://paircast.chaisz.com/invite/?roomId=…），iOS / Android 均可打开。
  3. 好友需在同一台服务器上有账号，并在服务配置里填写同一个服务器地址，再打开邀请链接。
  4. 房间内可文字聊天；长按消息可屏蔽（跟账号同步）或举报（提交给服务器管理员）。管理员可在「我的 → 后台管理 → 举报处理」中忽略举报或封禁用户。

5. 「我的」常用功能

  • 头像 / 昵称、修改密码、主题、语言
  • 服务配置、致谢与隐私/支持链接
  • 管理员另有后台管理：用户管理（停用 / 启用、删除普通用户）、添加用户、举报处理
  • 退出登录：保留本机服务配置
  • 删除账号：输入当前密码确认后，从服务器永久注销账号，并清除本机配置、会话与缓存；注销后管理员可用该邮箱重新为你建号。管理员账号不能在 App 内注销

6. 常见问题

  • 无法连接服务器：检查服务器地址拼写、是否需要 http://（仅局域网）以及网络；管理员可用 curl https://你的域名/health 确认服务在线。
  • 账号或密码错误 / 账号不存在：确认账号是在你填写的这台服务器上创建的。
  • 视频播不了：播放直链几小时后过期，回到片库重新打开即可。管理员：S3 Endpoint 必须是 API 地域域名，不要填 CDN 域名。
  • 两人进度不同步：确认两人连的是同一台服务器，且网络通畅。
