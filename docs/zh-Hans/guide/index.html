Paircast 使用说明

Paircast 是邀请制私人云同步播放工具：影片来自你自己的对象存储，账号由管理员在腾讯云 IM 中预置，应用内不提供注册。

最快上手：让管理员发给你一条 paircast://config?… 配置链接 → 在登录页打开「服务配置」粘贴导入 → 用分配的 User ID 登录。

1. 整体使用流程

  1. 完成服务配置（导入链接或手动填写）。
  2. 使用管理员分配的 User ID 登录（无需密码；UserSig 由本机根据 IM SecretKey 自动生成）。
  3. 在片库浏览 Bucket 中的 mp4 / m4v / mkv。
  4. 点开影片创建/加入房间，同步播放，并可边看边聊。
  5. 通过邀请链接把好友拉进同一房间。

2. 服务配置从哪里填、值从哪里拿

入口：登录页右上角 / 「我的」→ 服务配置。

「分享配置」生成的链接含 IM 与对象存储密钥，只发给可信好友。导入成功后请重新登录。

2.1 腾讯云 IM（必填）

App 字段从哪里获取说明
SDKAppID 腾讯云 IM 控制台 → 应用列表 / 应用配置 数字 App ID
SecretKey 同一应用的密钥管理（用于签发 UserSig） 保存在本机钥匙串；登录时本地生成 UserSig，用户不手动填
登录用的 User ID IM 控制台 → 账号管理（或你的用户导入方式） 需管理员预先创建；App 内无注册入口

控制台文档可参考：腾讯云 IM 文档。

2.2 对象存储（必填）

支持：七牛云（S3）、阿里云 OSS、腾讯云 COS、自建 MinIO。需填 AccessKey、SecretKey、Bucket、Endpoint；其余可选。

App 字段从哪里获取注意
提供商 按你实际使用的云选择 决定 Endpoint 校验规则
AccessKey / SecretKey 对应云厂商的密钥/访问密钥控制台 建议使用权限最小化的子账号密钥
Bucket 对象存储空间/桶名称 影片放在此桶内（可用 Prefix 限定目录）
Endpoint 该地域的 S3/OSS/COS API 域名（不要带 https:// 和路径） 不要把 CDN/自定义下载域名填到这里
Region（可选） 控制台显示的地域 ID 常可留空，App 会从 Endpoint 推断
自定义域名（可选） 绑定到 Bucket 的 HTTPS 域名 主要用于头像等下载；须已在云厂商开通证书
Prefix（可选） 桶内目录前缀，如 movies/ 只列出该前缀下的影片
HTTPS / 路径风格 URL — 公有云一般开 HTTPS；MinIO 常关 HTTPS、开 Path-Style

各厂商 Endpoint 示例

提供商控制台入口（示例）Endpoint 示例
七牛云 对象存储 Kodo（使用 S3 兼容域名） s3.cn-south-1.qiniucs.com
阿里云 OSS OSS 控制台 → Bucket 概览中的外网 Endpoint oss-cn-hangzhou.aliyuncs.com
腾讯云 COS COS 控制台 → 桶配置中的访问域名（地域域名） cos.ap-guangzhou.myqcloud.com
MinIO 自建服务地址 192.168.1.10:9000（主机:端口）

2.2.1 聊天贴纸（可选）

房间聊天的贴纸包从同一对象存储读取，目录约定：

  • {Prefix?}stickers/catalog.json — 包索引
  • {Prefix?}stickers/{pack_id}/pack.json — 包清单
  • {Prefix?}stickers/{pack_id}/… — 贴纸图片（png / gif 等）

管理员把贴纸包上传到 Bucket 的 stickers/ 后，成员即可在聊天输入栏的表情面板中使用。普通 Unicode 表情使用 Twemoji 图集展示。

仓库提供转换脚本：把本地表情包目录整理为上述结构后上传：

python3 Scripts/build-stickers.py --src /path/to/Stickers --out ./stickers-dist
# 将 stickers-dist/ 内容上传到 Bucket 的 stickers/ 前缀

2.3 扩展（可选）

App 字段从哪里获取用途
OpenSubtitles API Key OpenSubtitles Consumers 申请 在线检索/下载字幕
OMDb API Key OMDb API Key 按文件名补全海报等信息（不抓取豆瓣/IMDb）

3. 导入 / 分享配置

  1. 导入：服务配置 → 粘贴导入 → 确认覆盖 → 按提示重新登录。
  2. 也可直接打开管理员发来的 paircast://config?args=… 深链。
  3. 分享：配置完整后点「分享配置」，生成加密链接（含密钥，勿公开张贴）。

4. 登录与片库

  • 仅输入管理员分配的 User ID，点登录。
  • 若提示未完成配置，先回服务配置检查 IM + 对象存储是否齐全。
  • 片库为空时：确认 Bucket（及 Prefix）下确有 .mp4 / .m4v / .mkv，且密钥有列举/下载权限。

5. 同步观看与邀请

  1. 在片库点选影片 → 进入房间（房主可控制播放同步）。
  2. 邀请好友：房间内分享系统面板或复制邀请链接
    paircast://watch?roomId=…&movieId=…&hostUserId=…
  3. 好友需先完成同一套服务配置并登录对应 User ID，再打开邀请链接。
  4. 房间内可文字聊天；长按消息可屏蔽（本机）或举报。

6. 「我的」常用功能

  • 头像 / 昵称、主题、语言
  • 服务配置、致谢与隐私/支持链接
  • 退出登录：保留本机云配置
  • 删除账号：清除本机配置、会话、头像等；控制台里的 IM 账号需管理员另行停用

7. 常见问题

  • 配置链接无效：确认完整复制；导入失败不会覆盖已有配置。
  • 导入后仍像旧配置：按提示重新登录；导入后不要立刻用空的密钥栏再点保存。
  • Endpoint 报错：必须是 API 地域域名（见上表），自定义 CDN 域名填「自定义域名」栏。
  • 无法登录：User ID 是否已在 IM 控制台创建；SDKAppID/SecretKey 是否属于同一应用。
