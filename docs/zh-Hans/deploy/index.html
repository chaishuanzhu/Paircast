Paircast 服务端部署指南

Paircast 的服务器是开源的 GO-IM：它负责账号、聊天、播放同步、观影房间和片库。本文用 Docker 在一台 Linux 服务器上部署最小化版本，部署好后在 App 的「服务配置」里填服务器地址即可使用。

更多部署方式（Docker 全量、Kubernetes）和全部配置项见 GO-IM deploy/README.md。

0. 准备

项目说明
服务器Linux，2 核 2 GB 起；已装 Docker 20.10+ 与 Docker Compose v2
域名（推荐）如 im.example.com，解析到服务器，用于 HTTPS。仅局域网使用可以不要
发件邮箱（可选）任意支持 SMTP 的邮箱，用来给管理员和好友发初始密码；不配时初始密码在日志 / App 里显示
视频存储S3 兼容对象存储（阿里云 OSS、腾讯云 COS、七牛、MinIO 等）里放好的 mp4 / m4v / mkv，以及一对只读的访问密钥

需使用包含媒体库（/media、/room 接口）的 GO-IM 版本。

1. 启动服务

mkdir go-im && cd go-im
base=https://raw.githubusercontent.com/chaishuanzhu/GO-IM/main/deploy/docker
curl -fsSLO $base/docker-compose.minimal.yml
curl -fsSLO $base/config.minimal.json

# 必改：JWT 签名密钥
sed -i.bak "s|CHANGE_ME_run_openssl_rand_base64_48|$(openssl rand -base64 48 | tr -d '\n/+=')|" config.minimal.json

docker compose -f docker-compose.minimal.yml up -d
curl http://127.0.0.1:8080/health     # 返回 "status":"ok" 即就绪

这会启动 Gateway、MySQL、Redis 和 RustFS（存共享字幕、头像等小文件）。之后每次改 config.minimal.json 或 .env，都执行下面的命令让 gateway 重新加载（下文简称「重启 gateway」）：

docker compose -f docker-compose.minimal.yml up -d --force-recreate gateway

2. 配置 HTTPS（公网必做）

在服务器上用 Caddy 反向代理到 8080，它会自动申请证书并透传 WebSocket：

# /etc/caddy/Caddyfile
im.example.com {
    reverse_proxy 127.0.0.1:8080
}

完成后 App 里的服务器地址填 im.example.com。用 nginx 时记得透传 Upgrade / Connection 头。只在局域网用可跳过这一步，地址填 http://192.168.x.x:8080。

3. 管理员账号与邮件

在 config.minimal.json 里设置管理员邮箱。邮件（SMTP）可选：配了之后，管理员和新用户的初始密码会发到各自邮箱；不配也能用，管理员初始密码写在网关日志里，新用户的初始密码直接显示在 App 里由管理员转交。

"gateway": {
    "mail": {
        "enabled": true,
        "host": "smtp.exmail.qq.com",
        "port": 465,
        "username": "no_reply@example.com",
        "from": "Paircast <no_reply@example.com>"
    },
    ...
},
"admin_email": "you@example.com"

不用邮件时去掉 mail 段或设 "enabled": false。用邮件时 SMTP 密码不要写进配置文件，放在同目录的 .env：

MAIL_PASSWORD=你的SMTP密码

重启 gateway 后，网关会用 admin_email 自动创建管理员账号，并把随机密码发到该邮箱（没配邮件或发送失败时写在 docker compose -f docker-compose.minimal.yml logs gateway 里）。用这个邮箱和密码在 App 登录，首次登录会要求改密码。

4. 用户账号

Paircast App 不提供注册，账号都由管理员创建。

4.1 关闭自助注册（建议）

GO-IM 服务端默认开放 /register 注册接口。App 用不到它，建议关掉，二选一：

  • 配置文件：在 config.minimal.json 的 gateway.auth 里设 "disable_registration": true，然后 docker compose -f docker-compose.minimal.yml up -d --force-recreate gateway。
  • 运行时：用管理员令牌调用 curl -s -X POST $SERVER/admin/settings -d uid=管理员UID -d token=令牌 -d registration_open=false。后台改过之后以数据库里的值为准，配置文件里的值不再生效。

4.2 在 App 里添加用户

用管理员账号登录 App →「我的 → 添加用户」→ 填好友的邮箱（昵称可不填）→ 添加。配了邮件时初始密码自动发到对方邮箱；没配或发送失败时页面直接显示初始密码，点「复制」后私下转交（离开页面后不再显示）。对方首次登录时必须修改密码。

用户可在 App「我的 → 删除账号」输入密码后自行注销（管理员账号除外）。忘记密码时，管理员可用 /admin/users/delete 删除旧账号后用同一邮箱重新添加。

4.3 用命令行创建（可选）

SERVER=https://im.example.com
curl -s -X POST $SERVER/login -d account=you@example.com -d password='管理员密码'
# 记下返回中的 "uid" 和 "token"

curl -s -X POST $SERVER/admin/users/create \
  -d uid=管理员UID -d token=上一步的token -d email=friend@example.com -d nickname=小明

没配邮件或邮件没发出去时，响应里会带 initial_password，请私下转交给好友。

5. 片库

5.1 接入视频存储

在 config.minimal.json 的 gateway.media.sources 里添加视频源（密钥留空，下一步用环境变量注入）：

"media": {
    "sources": [
        {
            "id": "oss",
            "name": "我的片库",
            "type": "s3",
            "s3": {
                "endpoint": "oss-cn-hangzhou.aliyuncs.com",
                "bucket": "my-videos",
                "region": "cn-hangzhou",
                "prefix": "films/",
                "use_ssl": true,
                "path_style": false
            }
        }
    ]
}

在 .env 里加上密钥（compose 会以 GOIM_MEDIA_OSS_ACCESS_KEY / GOIM_MEDIA_OSS_SECRET_KEY 传给 gateway）：

MEDIA_OSS_ACCESS_KEY=只读AccessKey
MEDIA_OSS_SECRET_KEY=只读SecretKey

重启 gateway，日志出现 media library enabled 即生效，App 片库会列出 prefix 下的视频。

  • endpoint 填 S3 API 的地域域名（不含 https://），不要填 CDN 域名。七牛、MinIO 通常需要 "path_style": true。
  • 源 id 会写进影片 ID，上线后不要修改。id 不是 oss 时，在 compose 的 gateway environment 里按 GOIM_MEDIA_<大写ID>_ACCESS_KEY 的格式自行添加。
  • 可以配置多个源，App 片库页会出现片源切换。
  • 播放时服务器签发 6 小时有效的直链，视频流不经过服务器，所以密钥只需只读权限。

5.2 字幕与海报

  • 外挂字幕：和视频放在同一目录、同名即可，如 Inception.2010.mkv 配 Inception.2010.srt、Inception.2010.zh.ass、Inception.2010_en.vtt（支持 srt / vtt / ass / ssa）。
  • 海报与简介：优先读取同目录的 {主名}.nfo 与 {主名}-poster.jpg；没有时可以让服务器查 TMDB。
  • TMDB 刮削（可选）：.env 加 TMDB_ACCESS_TOKEN=…（TMDB 的 API Read Access Token）。
  • 在线字幕搜索（可选）：.env 加 OPENSUBTITLES_API_KEY=…。

5.3 表情包（可选）

表情包放在某个片源的桶里，目录下要有 catalog.json 与 {pack_id}/pack.json。用 Paircast 仓库里的脚本整理并上传：

python3 Scripts/build-stickers.py --src /path/to/Stickers --out ./stickers-dist
PAIRCAST_S3_ACCESS_KEY=… PAIRCAST_S3_SECRET_KEY=… \
  python3 Scripts/upload-stickers.py --endpoint oss-cn-hangzhou.aliyuncs.com --bucket my-videos

上传需要可写密钥（只在你本机使用，不要放到服务器上）。然后在 gateway.media 里设 "stickers_source": "oss"、"stickers_prefix": "stickers/"。

6. 在 App 里使用

  1. 打开 Paircast → 登录页右上角「服务配置」→ 服务器地址填 im.example.com → 保存。
  2. 用管理员或好友的账号登录，在片库选片、开房间、发邀请链接。

详见 使用说明。

7. 日常维护

docker compose -f docker-compose.minimal.yml logs -f gateway       # 查看日志
docker compose -f docker-compose.minimal.yml pull && docker compose -f docker-compose.minimal.yml up -d   # 升级
GOIM_TAG=x.y.z docker compose -f docker-compose.minimal.yml up -d  # 固定 / 回滚版本
  • 生产环境建议在 .env 固定 GOIM_TAG，并定期备份 MySQL 与 RustFS 数据卷。
  • 修改默认数据库密码与 RUSTFS_SECRET_KEY，gateway.check_origin 填写实际域名。
所有密钥（JWT、SMTP、存储、TMDB、OpenSubtitles）只放在服务器的 config.minimal.json / .env 里，不要发给用户，也不要提交到 git。用户只需要服务器地址和自己的账号。
