Paircast 隐私政策

生效日期：2026-11-02。Paircast 是邀请制的私人云同步播放工具，不提供公共片库，也不出售数据。

我们处理哪些信息

  • 账号与昵称：你输入的账号和密码只发送到你配置的自托管 GO-IM 服务器用于登录；昵称在你加入的房间内展示。
  • 头像：若你选择照片，会在本机压缩后上传到该 GO-IM 服务器，并向房间成员展示。
  • 聊天内容：仅发送到你所在的邀请制房间，经你的 GO-IM 服务器投递；播放同步信令实时转发，不落库。
  • 凭证：对象存储密钥与 GO-IM 登录令牌保存在本机安全存储（iOS 钥匙串 / Android 加密存储），用于访问你自己的服务。分享配置时使用 AES-GCM 包装，避免明文粘贴。
  • 可选第三方：若你填写 OpenSubtitles API Key 或 TMDB API 读取访问令牌，查询会发往对应服务。

不做什么

  • 不做广告追踪，不使用 App Tracking Transparency 广告标识。
  • 不运营公共影视目录，不把你的影片分发给其他未受邀用户。

第三方

邀请你的人所运营的自托管 GO-IM 服务器、兼容 S3 的对象存储，以及你主动配置的 OpenSubtitles 与 TMDB。其处理受各服务商条款约束。本产品使用 TMDB API，但未经 TMDB 认可或认证。

删除

在 App 内「我的 → 删除账号」可清除头像、本机配置与会话。GO-IM 账号由服务器运营方创建，如需停用或删除账号本身，请联系运营方。
