Paircast 隐私政策

生效日期：2026-11-02（2.1 版更新）。Paircast 是邀请制的私人云同步播放工具，不提供公共片库，也不出售数据。

我们处理哪些信息

  • 账号与昵称：你输入的账号和密码只发送到你配置的自托管 GO-IM 服务器用于登录；昵称在你加入的房间内展示。
  • 邮箱：用邮箱注册时，邮箱地址发送到该 GO-IM 服务器，用于发送验证码、作为登录账号；服务器通过其运营方配置的邮件服务发信。
  • 头像：若你选择照片，会在本机压缩后上传到该 GO-IM 服务器，并向房间成员展示。
  • 聊天内容：仅发送到你所在的邀请制房间，经你的 GO-IM 服务器投递；播放同步信令实时转发，不落库。
  • 凭证：App 只在本机安全存储（iOS 钥匙串 / Android 加密存储）保存 GO-IM 服务器地址与登录令牌。对象存储密钥与第三方令牌保存在 GO-IM 服务端，不会存到你的设备。
  • 片库：影片列表、播放链接、字幕与表情包都来自你的 GO-IM 服务器，视频直接从其签发的短时效链接加载。若服务器运营方启用了 OpenSubtitles 或 TMDB，你的字幕搜索词与片库影片名会由服务器发往对应服务。

不做什么

  • 不做广告追踪，不使用 App Tracking Transparency 广告标识。
  • 不运营公共影视目录，不把你的影片分发给其他未受邀用户。

第三方

邀请你的人所运营的自托管 GO-IM 服务器，以及该运营方在服务端配置的兼容 S3 的对象存储、OpenSubtitles 与 TMDB。其处理受各服务商条款约束。本产品使用 TMDB API，但未经 TMDB 认可或认证。

删除

在 App 内「我的 → 删除账号」输入当前密码后，GO-IM 服务器会永久删除你的账号记录（邮箱、昵称、头像、密码），并清除本机配置、会话与缓存。已发送到房间的聊天消息由服务器运营方保管，如需删除请联系运营方。管理员账号需由服务器运营方处理。
