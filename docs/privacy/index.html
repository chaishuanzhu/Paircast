Paircast 隐私政策

生效日期：2026-08-24。Paircast 是邀请制的私人云同步播放工具，不提供公共片库，也不出售数据。

我们处理哪些信息

  • 账号标识与昵称：你输入的 IM 用户名、昵称，用于登录腾讯云 IM 和房间内展示。
  • 头像：若你选择相册照片，会压缩后上传到你配置的对象存储，并在 IM 资料中保存对象键。
  • 聊天内容：仅发送到你所在的邀请制房间，经腾讯云 IM 投递。
  • 云凭证：对象存储与 IM 密钥保存在本机钥匙串，用于访问你自己的存储与通讯服务。分享配置时使用 AES-GCM 包装，避免明文粘贴。
  • 可选第三方：若你填写 OpenSubtitles / OMDb API Key，查询会发往对应服务。默认不请求豆瓣或 IMDb。

不做什么

  • 不做广告追踪，不使用 App Tracking Transparency 广告标识。
  • 不运营公共影视目录，不把你的影片分发给其他未受邀用户。

第三方

腾讯云 IM、兼容 S3 的对象存储，以及你主动配置的 OpenSubtitles 与 OMDb。其处理受各服务商条款约束。

删除

在 App 内「我的 → 删除账号」可清除本机配置、会话、昵称/头像对象。预置 IM 账号如需从控制台移除，请联系运营方。
